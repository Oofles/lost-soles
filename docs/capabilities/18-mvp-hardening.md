## The public surface: D-123 Trigger C, C-1 (ticket `0114`)

`08-security-privacy.md` §2.4, C-1: *enumerate the surface.* This is every path reachable
**without** a Cognito session, as built on 2026-10-22, checked against the live account. A path
not on this list that answers a signed-out request is a finding. If it serves cell data, trace
geometry, or anything derived from them, it is **Trigger C** and reopens D-123.

| Public path | What it serves | Why it is safe |
|---|---|---|
| **`ingest-webhook` Function URL** (`AuthType: NONE`; D-345, D-349) | `GET` answers Strava's `hub.challenge`; `POST` accepts an event and returns 200 with no body | Reads nothing, returns nothing, holds no credential (`08` §4.5). The only Lambda in the app with a Function URL. Every other function has none, as listed live. |
| **The sign-in page**, `/` signed out | The Amplify UI Authenticator, plus Cognito's own public auth endpoints (`cognito-idp`, the identity pool) | Self-signup and guest identities are off, asserted on every deploy by `check-auth-posture.mjs`. `/` carries no home coordinate signed out (`0053`). |
| **Static assets**: `/_next/static/*`, `/_next/image`, `/maplibre/*`, `favicon.ico`, images | Build output and the vendored MapLibre worker | `check-prerender-no-cell-data.mjs` (C-2) scans `.next/static` for cell and trace shapes on every build. `check-bundle-leak.mjs` and `check-home-not-in-client.mjs` scan it for secrets and the home coordinate. |
| **Everything under `public/`**, served by Amplify's CDN **without running `middleware.ts`** | Today: `/maplibre/*`, and `/fog-fixtures/fog-{50k,150k,500k}.bin` (the `0059` perf harness) | The fog fixtures are **synthetic** cells around `PERF_ORIGIN` (30° N, 100° E), generated by `lib/fog/perf/synthetic.ts`, never anyone's map. **A real explored set must never be put in `public/`**, because the middleware matcher does not gate it. Verified live: `/fog-fixtures/fog-50k.bin` answers 200 signed out. |
| **Prerendered pages**: `/_not-found`, `/skills`, `/skills/[skillId]`, `/log`, `/dev/tickets` | Static HTML/RSC rendered at build time, from committed data only | The middleware still 307s them signed out. They are on `check-prerender-no-cell-data.mjs`'s allowlist, and a new prerendered route fails the build until it is added there with a reason (C-2). |
| **The tiles CloudFront distribution** (`lost-soles-tiles`, private bucket behind OAC; D-226, D-250) | The generic pmtiles basemap | Identical for every user, containing **zero** Lost Soles data. **The tile distribution serves the generic basemap only, and the explored set is never baked into a tile.** Direct S3 access 403s (`0052`). |
| **AppSync GraphQL endpoint** | Nothing to a signed-out caller | `AMAZON_COGNITO_USER_POOLS` default, `AWS_IAM` for authenticated identities only. Unauthenticated identities are off. |

**Not public, and why (C-3, C-4).** Every `app/**/route.ts` handler is wrapped in
`lib/http/no-store.ts` `withNoStore`, so every response it returns is `Cache-Control: no-store,
private`. The one exception is D-228's carve-out: the 200s of `/api/fog/blob/[gen]` and
`/api/fog/lastrun/[gen]` are `private, max-age=31536000, immutable`. `check-route-cache-control.mjs`
fails the build otherwise. A signed-out request to any `/api/*` route is a 404 from `middleware.ts`.
The explored set (`users/<sub>/explored/explored-r11.<gen>.bin`, D-237) is served **only** through
those authed routes with `sub` re-derived server-side (D-228). An anonymous GET of the predictable S3
key answers **403**: the bucket blocks public access and no bucket policy allows an anonymous
principal (`amplify/explored-set-not-public.test.ts`). No signed URL exists (D-228).
