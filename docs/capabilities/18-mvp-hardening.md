## The public surface: D-123 Trigger C, C-1 (ticket `0114`)

`08-security-privacy.md` §2.4, C-1: *enumerate the surface.* This is every path reachable
**without** a Cognito session, as built on 2026-10-22, checked against the live account. A path
not on this list that answers a signed-out request is a finding. If it serves cell data, trace
geometry, or anything derived from them, it is **Trigger C** and reopens D-123.

|---|---|---|

**Not public, and why (C-3, C-4).** Every `app/**/route.ts` handler is wrapped in
`lib/http/no-store.ts` `withNoStore`, so every response it returns is `Cache-Control: no-store,
private`. The one exception is D-228's carve-out: the 200s of `/api/fog/blob/[gen]` and
`/api/fog/lastrun/[gen]` are `private, max-age=31536000, immutable`. `check-route-cache-control.mjs`
fails the build otherwise. A signed-out request to any `/api/*` route is a 404 from `middleware.ts`.
The explored set (`users/<sub>/explored/explored-r11.<gen>.bin`, D-237) is served **only** through
those authed routes with `sub` re-derived server-side (D-228). An anonymous GET of the predictable S3
key answers **403**: the bucket blocks public access and no bucket policy allows an anonymous
principal (`amplify/explored-set-not-public.test.ts`). No signed URL exists (D-228).

**Re-processing after the receipt TTL is not literally write-free.** Within the receipt's 90
days the pipeline sends nothing. After the receipt expires, and on `reingest`, it applies zero
cell writes and zero ledger, SkillState or Profile writes. It still sends four kinds of write,
and `idempotency.test.ts` names them:

- the unconditional `writeAggregates` `ADD exploredChildren 0`. It applies and changes no attribute.
- a regenerated explored blob under a new `generation`, over identical cells.
- the T3 re-put with the first award (D-254, D-260).
- the receipt's DONE.

None of them moves XP or the map.
